This is just a simple spaceship dodge game. It is my first game and first Hack Club project. You can use your mouse to move the spaceship. Note, it has only been tested on Google using an Apple device. To restart the game if you lose. hust hit the refresh button. Move your mouse to get started. Have fun :)!
